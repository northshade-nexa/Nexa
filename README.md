# Nexa

Nexa is a modern Android social network built with Android Studio.

## Features

- 📱 Modern social feed
- 💬 Real-time private messaging
- 🌍 Public communities (Worlds)
- ❤️ Likes, comments and follows
- 🔎 Smart search by tags and users
- 🖼️ Image sharing
- 🔔 Notifications
- 🛡️ Moderation system
- 🤖 Interest-based recommendation algorithm
- 🌙 Light & dark theme

## Tech Stack

- Java/Kotlin (Android Studio)
- Firebase Authentication
- Cloud Firestore
- Firebase Cloud Messaging
- Firebase Remote Config
- Cloudinary
